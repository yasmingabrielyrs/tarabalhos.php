# tarabalhos.php


explicação da pasta "projeto"
Eu entendi que o protect.php serve para verificar se eu estou logado e impedir o acesso de quem não estiver. O código de cadastro serve para adicionar novos usuários no banco de dados, com nome, e-mail e senha. O index.php é a página de login, onde eu coloco meu e-mail e senha. Se os dados estiverem corretos, eu entro no painel. O logout.php serve para encerrar minha sessão e sair da conta. O painel.php é a página que eu acesso depois do login, onde aparece meu nome e a opção de sair.
